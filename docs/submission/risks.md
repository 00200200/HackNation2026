# Risks and existing mitigations

The references below describe the inspected branch. A mitigation is an implemented control,
not proof that the risk is resolved. Unimplemented controls are labelled **not mitigated**.
Saved outcome metrics are quoted in [architecture.md](architecture.md) directly from
[evals/results/latest.json](../../evals/results/latest.json); that run has `overall_pass: false`.

| Risk and failure scenario | Mitigation present in code, with file:line | Residual risk / absent control |
|---|---|---|
| Hallucinations: a model invents a quote, misstates a claim or labels a quotation incorrectly. | Extraction is instructed not to decide truth (`prawdowid/verifier.py:80`). `judge.verify_quotes` accepts only a matching span in the cited title/fragment and displays the source's own words (`prawdowid/judge.py:192`, `prawdowid/judge.py:208`). Verdicts follow `decide()`; conflicts and insufficient evidence lead to abstention (`prawdowid/judge.py:254`). The linked page is excluded from its own evidence (`prawdowid/rerank.py:116`). | Text occurrence cannot prove that a quote supports the claim. Semantic errors in extraction, relevance, stance and missing context remain possible. Fact Check titles may be the only evidence text. Independent human review and a correction/appeal workflow: **not mitigated**. Citation correctness is unmeasured. |
| Source bias: the selected publishers or copied agency reports skew the answer. | An explicit source allowlist (`prawdowid/websearch.py:42`), URL and near-duplicate removal (`prawdowid/rerank.py:116`, `prawdowid/rerank.py:162`), and grouping of shared publisher, quote or agency origins (`prawdowid/judge.py:353`) limit repeated evidence. Archival/undated material gets limitations (`prawdowid/judge.py:403`). EUvsDisinfo has type `disinfo_database`, outside the types counted as sufficient alone (`prawdowid/websearch.py:52`, `prawdowid/judge.py:38`). | Allowlist selection and reliable-type weighting are team policy; they have no independent diversity audit. Google review results are not restricted to the web allowlist. Missing dates, stale cache entries and institutional/editorial bias remain. Measured bias across topics or viewpoints: **not mitigated**. |
| Privacy: a submitted claim, source passage or URL contains personal data and leaves the host or persists in a channel/log. | Regex masking of obvious personal data (`prawdowid/privacy.py:23`) is called for outgoing web queries (`prawdowid/websearch.py:158`) and dormant own-store query terms (`prawdowid/cache.py:201`). The bot uses slash commands without privileged message-content intent (`prawdowid/discord_bot.py:200`). API summary logs use input length rather than full raw input (`prawdowid/app.py:91`). | Raw input goes to the extraction model (`prawdowid/verifier.py:274`); Google and MCP receive claim text (`prawdowid/pipeline.py:128`); claim logs and link URLs/results are unmasked (`prawdowid/pipeline.py:332`, `prawdowid/verifier.py:248`, `prawdowid/link.py:207`). Names and addresses are outside the regex. Discord replies are public to the channel (`prawdowid/discord_bot.py:214`). Full masking before all external calls, defined log retention, consent/session deletion and provider processing agreements: **not mitigated**. |
| Prompt injection: input or a retrieved page asks the model to change its output. | Registered data tags and separate instructions are used for extraction (`prawdowid/verifier.py:71`, `prawdowid/verifier.py:80`), reranking (`prawdowid/rerank.py:50`) and judgement (`prawdowid/judge.py:88`). Models are asked to ignore instructions inside data. Extraction and judge flags create security events without repeating attack wording (`prawdowid/verifier.py:319`, `prawdowid/judge.py:186`), shown by channels (`frontend/public/app.js:61`, `prawdowid/discord_bot.py:100`). Quote validation limits invented evidence. | The same attacked model detects the attack. There is no independent detector, and reranking has no security-event flag. The latest quick injection metric passes, but is based on a single injection case; it does not demonstrate broad resistance (see the cases in `evals/results/latest.json`). Reliable prevention of instruction following or event suppression: **not mitigated**. |
| Availability: a key is missing, provider is slow, rate limited or unavailable. | API rate limit and timeout (`prawdowid/app.py:21`, `prawdowid/app.py:77`); bounded provider operations (`prawdowid/factcheck.py:70`, `prawdowid/euvsdisinfo.py:69`, `prawdowid/websearch.py:184`); per-claim deadline and bounded retry (`prawdowid/pipeline.py:65`). Total retrieval failure and deadline expiry give `not_checked`; extraction failure returns a technical notice (`prawdowid/verifier.py:262`). Containers have health/restart policies (`compose.yaml:4`). | Extraction and link fetch share the check deadline (`prawdowid/verifier.py:221`, `prawdowid/verifier.py:262`). The pipeline maps judge-model failure to `not_checked` (`prawdowid/pipeline.py:257`); a failed retry judge can keep a first-pass result, with a warning, when first-pass candidates existed (`prawdowid/pipeline.py:99`). A successful empty provider can lead to abstention even while others fail. Missing source keys are not forwarded by base Compose, and its cache path is not prepared for `nobody` (`compose.yaml:6`, `Dockerfile:19`, `prawdowid/cache.py:136`). Global backpressure, provider failover and measured concurrent capacity: **not mitigated**. |
| Abuse: many clients exhaust the model budget or use malicious URLs and output text. | Input size/URL validation and IP rate limiting (`prawdowid/app.py:37`, `prawdowid/app.py:77`). User URL fetching checks public IPs on each connection, caps redirects/body size and rejects access barriers (`prawdowid/link.py:114`, `prawdowid/link.py:176`, `prawdowid/link.py:237`). Browser rendering uses text nodes (`frontend/public/app.js:29`); nginx sets CSP and overwrites forwarded IPs (`frontend/nginx.conf:8`, `frontend/nginx.conf:21`). Discord escapes user/source text, disables mentions and previews (`prawdowid/discord_bot.py:37`, `prawdowid/discord_bot.py:218`). | IP limits do not cover distributed clients; Discord users share one IP quota. Rate-limit state is local to a process. No authentication, per-user quota, global concurrency/spend cap or abuse reporting workflow: **not mitigated**. Web evidence fetching uses a domain allowlist, not the DNS/IP guard used by the submitted-link path (`prawdowid/websearch.py:210`). |
| Unlicensed or stale archives: successful web fetches are cached without confirmed rights or deletion timing. | Own PostgreSQL retrieval is disabled (`prawdowid/pipeline.py:153`). The dormant store has licence/expiry metadata and cascade deletion (`db/migrations/001_source_store.sql:18`, `db/migrations/001_source_store.sql:26`, `db/migrations/001_source_store.sql:31`); seeding invokes expiry deletion (`prawdowid/corpus.py:95`). robots.txt is checked for evidence fetches (`prawdowid/websearch.py:316`). | Licence metadata is not a permission check. JSONL still stores extracted pages, skips refresh by URL and has no expiry (`prawdowid/cache.py:136`). The dormant database deletion is seed-triggered, not scheduled. Publisher restrictions include PAP and AFP; see [sources.md](sources.md). Rights enforcement, automated cache expiry and session deletion: **not mitigated**. |

Code references are relative to this branch; use the named functions when following them on a
later stack tip. Proposed work is deliberately not described as a safeguard already delivered.
The draft materials contain no input transcripts, provider credentials or personal datasets.
